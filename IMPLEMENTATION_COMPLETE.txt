================================================================================
TECHNICAL DETAILS
================================================================================

Test Duration: 15 seconds (configurable in agents)
Capture Rate: 2 Hz (every 0.5 seconds)
Samples per Test: 30 frames
Parallel Agents: 2 (X11 + Wayland on compatible systems)

Screen Capture Tools:
  X11:     scrot, import (ImageMagick)
  Wayland: grim, gnome-screenshot, spectacle

Output Format: JSON with detailed metrics + human-readable summary

Termination Method:
  1. SIGTERM sent to target PID
  2. Wait 1 second
  3. Check if still running
  4. If running: SIGKILL

================================================================================
METRICS COLLECTED
================================================================================

Per-Frame Metrics (30 samples):
  • timestamp         - Time since test start (seconds)
  • shape             - Frame dimensions [height, width, channels]
  • mean_rgb          - Average RGB values [0-255]
  • std_rgb           - Standard deviation of RGB
  • min_rgb           - Minimum RGB values
  • max_rgb           - Maximum RGB values
  • red_overlay_detected - Boolean (>1000 red pixels)
  • red_coverage_percent - % of screen covered
  • red_pixel_count   - Total red pixels
  • red_center_x/y    - Center of mass
  • red_movement_pixels - Distance from previous frame
  • is_moving         - Boolean (moved >10 pixels)

Summary Statistics:
  • total_samples          - Number of frames captured
  • red_detected_count     - Frames with overlay detected
  • red_detected_percent   - Detection rate %
  • avg_red_coverage       - Average coverage %
  • max_red_coverage       - Peak coverage
  • avg_movement           - Average pixel movement
  • max_movement           - Peak movement
  • is_animated            - Boolean (avg movement >5px)

================================================================================
SUCCESS CRITERIA
================================================================================

Detection Rate:
  ✓ >80%    - Excellent, overlay rendering consistently
  ⚠ 50-80%  - Moderate, some frames missing overlay
  ✗ <50%    - Poor, overlay not rendering correctly

Animation:
  ✓ >5px avg  - Animation working as expected
  ⚠ 2-5px     - Minimal movement
  ✗ 0px       - No animation (failure)

Coverage:
  ✓ 5-20%   - Expected for test rectangle
  ⚠ 20-50%  - Larger than expected
  ✗ <5%     - Too small, barely visible
  ✗ >50%    - Too large, covering most of screen

================================================================================
CLOSED FEEDBACK LOOP
================================================================================

The system provides a complete closed feedback loop:

1. Visual Output
   ↓ Main program renders red overlay on screen
   
2. Automated Capture
   ↓ Test agents screenshot every 0.5 seconds
   
3. Numerical Conversion
   ↓ Pixels analyzed → RGB stats, coverage, movement
   
4. Analysis
   ↓ Compare against success criteria
   
5. Feedback Generation
   ↓ Specific pass/fail with actionable feedback:
     ✓ "Good overlay detection rate"
     ✗ "Low detection rate - overlay not rendering"
     ⚠ "No animation detected - check movement logic"
   
6. Iterate
   ↓ Fix issues based on feedback
   
7. Re-test
   ↓ Return to step 1

KEY: No human observation required at any step!
