FEEDBACK LOOP FOR CODING AGENTS
================================

┌────────────┐
│   Change   │  Coding agent modifies overlay code
│    Code    │  (e.g., fix transparency, movement, etc.)
└─────┬──────┘
      │
      ▼
┌────────────┐
│    Run     │  ./run_tests.sh
│   Tests    │  Automated 15-second test
└─────┬──────┘
      │
      ▼
┌────────────┐
│  Capture   │  Test agents screenshot every 0.5s
│   Visual   │  30 samples collected
└─────┬──────┘
      │
      ▼
┌────────────┐
│  Convert   │  Each screenshot → numerical metrics
│    to      │  RGB stats, coverage %, movement, etc.
│  Numbers   │
└─────┬──────┘
      │
      ▼
┌────────────┐
│  Analyze   │  Compare against expected behavior
│            │  Detection rate, animation, coverage
└─────┬──────┘
      │
      ▼
┌────────────┐
│ Generate   │  ✓ Pass: overlay working
│ Feedback   │  ❌ Fail: specific issue identified
└─────┬──────┘
      │
      ├───────→ Pass? ─────→ Done ✓
      │
      └───────→ Fail? ─────→ Return to "Change Code"
                             (with specific feedback)


KEY: Loop is closed because:
1. Visual output is automatically captured
2. Converted to measurable numerical data
3. Compared against success criteria
4. Specific, actionable feedback generated
5. No human observation required
