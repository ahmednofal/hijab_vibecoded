# 🚀 Quick Start Guide - Hijab by Copilot (Windows)

## For Impatient Users 😊

### Step 1: Check Your System (Optional)
Double-click: **`check_system_windows.bat`**

This will tell you if everything is ready.

### Step 2: Setup (First Time Only)
Double-click: **`setup_windows.bat`**

Wait for it to finish (may take 2-5 minutes).

### Step 3: Run the Application
Double-click: **`run_windows.bat`**

That's it! 🎉

---

## What You'll See

1. A console window with status messages
2. A transparent red rectangle moving across your screen
3. This is test mode - the rectangle shows the overlay is working

## How to Exit

Press **Ctrl+C** in the console window, or just close it.

---

## What if Something Goes Wrong?

### "Python is not recognized..."
➡️ Install Python from [python.org](https://www.python.org/downloads/)
   Make sure to check **"Add Python to PATH"** ✅

### "Failed to install dependencies..."
➡️ Open Command Prompt as Administrator and try again

### "Overlay not visible..."
➡️ Check: Settings → Personalization → Colors → Transparency effects: **ON**

### Still stuck?
➡️ Read **WINDOWS_README.md** for detailed troubleshooting
